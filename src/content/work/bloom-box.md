#### Application de gestion de réservations – API REST et interface administrateur

Ce projet illustre mes compétences en développement full-stack. J’ai conçu une API REST (API Platform) sécurisée permettant la gestion complète des réservations, des clients et des chambres.
Le back-end a été développé en PHP apartir du Framework symfony 7. L’API expose différentes routes CRUD testées via Postman, comme on peut le voir sur la capture ci-dessus.

### Frontend
----
Côté front-end, j’ai intégré une interface moderne et responsive développé avec angular, permettant d’afficher dynamiquement les données et d’améliorer l’expérience utilisateur.
J’ai également mis en place la validation des entrées, la gestion des erreurs, et le respect des bonnes pratiques OWASP pour assurer la sécurité.

Ce projet démontre ma capacité à concevoir une architecture claire, à documenter les endpoints, et à déployer une solution fonctionnelle et évolutive.
